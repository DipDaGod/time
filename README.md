# Split-Flap Clock

A single-file, no-dependency live clock with a mechanical split-flap board look, multiple themes, and a classic digital mode.

🔗 [Visit Website](https://dipdagod.github.io/time/time.html)

## Features

- **Live clock** — updates every second, flap-cards animate on digit change
- **5 color themes** — Flap, Daylight, Neon, Paper, Terminal
- **2 clock styles** — Flip Board (mechanical) or Classic (plain glowing digits)
- **12h / 24h format** — with AM/PM indicator in 12h mode
- **Show/hide seconds** — toggle switch
- **Works fully offline** — download the file and open it on your browser.
- **Settings persist** — saved in `localStorage`, restored on reload
- **Fullscreen mode** — button in the corner triggers true fullscreen; controls auto-hide.
